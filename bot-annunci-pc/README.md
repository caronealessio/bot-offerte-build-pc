# Bot annunci PC

Cerca componenti PC usati (Subito, eBay) e nuovi (Trovaprezzi) e invia avvisi su Telegram con un'etichetta anti-truffa.
Gira gratis su GitHub Actions.

Per installarlo segui **[GUIDA.md](GUIDA.md)**.

- Configurazione: `config.yaml`
- Storico prezzi: `data/stato.json` (aggiornato automaticamente)
- Test offline: `python tests/test_bot.py`
